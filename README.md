# Seals

Mod de Minecraft sobre sellos ("seal" en inglés).

- **Minecraft:** 1.20.1
- **Forge:** 47.4.10 o superior
- **Java:** 17

## Compilar

```bash
./gradlew build
```

El `.jar` queda en `build/libs/`. Cópialo a la carpeta `mods` de tu instancia de Forge 1.20.1.

## Probar en desarrollo

```bash
./gradlew runClient
```

En Windows usa `gradlew.bat` en lugar de `./gradlew`.
